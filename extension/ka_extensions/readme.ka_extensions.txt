Purpose of this package
=======================

Ka Extensions is a set of files shared among other extensions. It includes 'kamod' engine as well as other useful
tools.


Requirements
=======================
- Opencart 4.1.0.3 and newer


How to install
=======================

1) Log in to your store back-end under an administrator account and upload the extension archive 
   at the 'Extension Installer' page.
   
2) On the 'Installed Extensions' list click the 'Install' button next to the 'Ka Extensions' extension.

3) Go to the 'Modification' page. Click the enable button next to the 'Ka Extensions Ocmod' modification name.

4) Reload the 'Modification' page two times. A new 'Ka Extensions' menu element should appear under 'Extensions' menu. 
   If it does not appear, restart the browser. If this does not help, please contact us. We provide free support 
   the for 'Ka Extensions' library.

5) All extensions developed by our team will appear there. You can hide that menu with standard user permissions. The page 
   is always shown to administrators with a 'modify' access at the 'User Permissions' page.   
   
6) Make sure that the store front-end is available for customers and that it is functional.
